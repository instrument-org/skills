The same spring, for Motion

<motion.div
  initial={{ y: 320, opacity: 0 }}
  animate={{ y: 0, opacity: 1 }}
  transition={{ type: "spring", visualDuration: 0.45, bounce: 0.25 }}
/>

// As physics: stiffness 135, damping 17.5, mass 1.

Settled where Motion would call it settled: within half a percent of the end and moving slower than a hundredth of the travel a second, checked every 50 ms, which is why the figure lands on a round number. Bounce and visual duration become stiffness and damping by Motion's own formula, so the two blocks describe one spring. The dials are dialkit, which needs the network; the sheet and the CSS do not. Nothing you set leaves this page: the dials remember their last position in this browser and nowhere else, and Reset puts them back to the opening setting.
